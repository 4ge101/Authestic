# Eshal

I started Eshal with a simple idea: make learning a little easier, more engaging, and more enjoyable for autistic children.

I want to bring stories, games, communication activities, and useful resources together in one place, so children and caregivers can find what they need without jumping between different platforms.

## What I'm Building

- **Stories** to make learning through storytelling more engaging.
- **Games and activities** to encourage exploration and learning.
- **Communication** tools and activities to support everyday expression.
- **Life skills** activities for learning through everyday experiences.
- **Resources** for children, parents, and caregivers.

## Built With

- React and TypeScript
- Rust
- PostgreSQL

## Current Status

Eshal is still a work in progress. I'm building the frontend first, then connecting it to a real backend and database.

There's a lot left to do, but the goal is to make something genuinely useful, accessible, and easy to use.
